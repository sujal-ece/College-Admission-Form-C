# College Admission Form in C

A console-based College Admission Form developed in C as a practical programming project.

## Overview

This program simulates a college admission process through a command-line interface. It collects student information, academic details, stream and subject choices, degree preferences, and specialization choices.

The program then calculates the student's aggregate percentage and checks the admission eligibility criteria based on the selected stream and subjects.

## Features

- Student personal information collection
- Parent and guardian information
- Stream selection:
  - Science
  - Commerce
  - Arts / Humanities
- Subject and group selection
- Degree and field selection
- Engineering specialization selection
- Marks calculation and percentage calculation
- Admission eligibility filtering
- Provisionally admitted / rejected result
- Detailed rejection reasons when eligibility criteria are not met

## C Concepts Used

- Variables and data types
- `if`, `else if`, and `else`

- Strings and character arrays
- `fgets()`
- `strcmp()`
